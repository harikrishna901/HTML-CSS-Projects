# 🏋️ GymRock Fitness Website

## 🔗 Live Demo

🚀(https://harikrishna901.github.io/HTML-CSS-Projects/GymRock-Fitness-Website/)


A responsive multi-section fitness website built using HTML and CSS. The project presents a complete gym and fitness website layout with dedicated sections for services, fitness features, testimonials, trainers, FAQs, and contact information.

## ⭐ Featured Project

**GymRock Fitness Website** is one of the featured projects in this repository because it demonstrates my ability to build a complete multi-section website and organize a front-end project using a clean folder structure.

## 📸 Project Overview

The website includes:

- Responsive navigation
- Hero section
- About section
- Services section
- Fitness features
- Why Choose Us section
- Customer testimonials
- Trainer profiles
- Social media links
- FAQ section
- Contact form layout
- Footer

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- CSS Flexbox layouts
- CSS Grid layouts
- Hover effects and transitions
- Background images
- Multi-section single-page website
- Native FAQ accordion using HTML `<details>` and `<summary>`
- Organized assets and CSS structure

## 📱 Responsive Design

The website has been optimized for:

- 💻 Desktop screens
- 📲 Tablets
- 📱 Mobile devices

The layout adapts by changing multi-column sections into fewer columns or single-column layouts on smaller screens.
