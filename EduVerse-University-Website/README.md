# 🎓 EduVerse University Website

A modern and responsive university website built using **HTML and CSS**. The project presents university courses, global campuses, facilities, student reviews, and enrollment opportunities through a clean and visually appealing interface.

## 📌 Project Overview

EduVerse University Website is a front-end educational website designed to showcase different aspects of a university.

The website includes multiple pages and sections that provide information about courses, campus locations, facilities, blogs, contact information, and student experiences.

## ✨ Features

- 🏠 Responsive navigation bar
- 🎓 University homepage
- 📚 Courses information
- 🌍 Global campus showcase
- 🏫 University facilities section
- 📖 World-class library
- 🏀 Sports and playground facilities
- 🍽️ Cafeteria and food facilities
- 💬 Student reviews and testimonials
- ⭐ Student ratings
- 📞 Contact page
- 📝 Blog page
- 🎯 Course page
- ℹ️ About page
- 📱 Responsive design using media queries
- 🎨 Modern user interface
- ✨ Font Awesome icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
