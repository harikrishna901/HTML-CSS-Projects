# 🍔 Foodie Restaurant Website

A modern and visually appealing restaurant website built using **HTML and CSS**. The website showcases food items, restaurant information, customer reviews, chefs, and an order section.

## 🌐 Live Demo

https://harikrishna901.github.io/HTML-CSS-Projects/EduVerse-University-Website/

## 📌 Project Overview

Foodie is a responsive restaurant website designed to provide users with an attractive interface for exploring food items and restaurant services.

The website includes multiple sections such as:

- Home
- About Us
- Menu
- Gallery
- Customer Reviews
- Order Section
- Team
- Footer

## ✨ Features

- 🍔 Attractive food and restaurant landing page
- 🏠 Home section with navigation bar
- ℹ️ About Us section
- 🍕 Interactive food menu cards
- ❤️ Favorite/heart icons
- ⭐ Food ratings
- 🖼️ Food gallery
- 💬 Customer review section
- 🛒 Order form
- 👨‍🍳 Chef and team section
- 📱 Responsive website design
- 🔗 Navigation links to different sections
- 🎨 Modern UI using CSS
- ✨ Icons using Font Awesome

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
